Colony Flow — Game Design Document

Puzzle “kiến tha thức ăn” của ABI Games: xếp hộp kiến vào 5 slot để ăn hết bức tranh pixel. Tài liệu đọc ngược từ v1.0.80 với code decompile (Cpp2IL + Ghidra), config đóng gói, Remote Config, CDN level, backend và playtest.

33 trang tính năng12 bài phân tích2.700 level giải mã165 ảnh chụp1.494 class game21.760 method pseudo-C72 config + RC key72 endpoint REST
