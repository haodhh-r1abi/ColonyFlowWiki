Tổng quan

CODE Module GameBackendModule (Zenject) gọi REST JSON tới https://colony.dinogoglobal.com (test 136.112.78.71:14600, dev localhost:3000) — đọc từ scene GameplayScene. Đăng nhập Google Play Games (colony_auth_provider = gpg), JWT access + refresh token, claim theo device id. Cloud save có meta/resolve xung đột (ModalCloudSaveRestore). SERVER/CDN Endpoint nhóm: auth, player, cloud-save, leaderboard, team, clan, royal-league, weekly-contest (chưa có trên server), users/purge. Mã nguồn module còn thư mục Examples và hằng BASE_URL localhost — module dùng chung giữa các game (host cũ mahjong.aagamestudio.com).
