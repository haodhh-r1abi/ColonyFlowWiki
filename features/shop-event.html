Tổng quan

CODE ShopEventConfigSource tải shop_events.json và catalog Addressables catalog_shop.bin từ CDN shop để thêm gói sự kiện + cosmetic (khung, avatar) mà không cần cập nhật app. SERVER/CDN Ngày 22/10 hai file còn 404; 30/10/2026 đã có sự kiện “Halloween 2026” (30/10 → 02/11, bản Android ≥ 1.0.81, tự bật popup, 1 gói “mega” mua tối đa 1 lần). Catalog CDN chứa popup/nút của 6 sự kiện: WorldCup, Bowl, Carnival, BackToSchool, LaborDay, Halloween — tức là các offer sự kiện trước đây đã chuyển từ event_offer của Remote Config sang đây. PLAYTEST Playtest 1.0.83: icon dơi tím ở cột phải Home (đếm giờ), popup “Spooky Bundle” 6.000 coin + khung đặc biệt + 4 booster ×2, giá 394.000 ₫; bảng Google Play ghi “Group Pack 4”. CODE Gói tier N bán bằng SKU group_pack_N (PurchaseLedger.PackageNameForTier ở 1.0.83); 1.0.80 dùng tiền tố evt_t nhưng sự kiện đòi ≥ 1.0.81. REMOTE CONFIG shop_event_config.Events = [] không ảnh hưởng: sự kiện lấy thẳng từ CDN.
