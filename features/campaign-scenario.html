Tổng quan

CODE CampaignScenarioManager đọc tên campaign AppsFlyer (CampaignNameFetcher gọi wood.aagamestudio.com/api/appflyerdata/), so khớp với danh sách campaign của từng kịch bản (Exact/Prefix/Contains), rồi ghi đè banner, inter (level bắt đầu, capping, tối đa/ngày, sau rewarded, bỏ inter đầu), inter khi thua, quảng cáo nạp tim, popup No Ads, Daily reward, và ẩn/chỉ hiện một số gói Shop. Sau khi mua IAP trong phiên: PostPurchase có thể ẩn banner và nhân capping. Không khớp kịch bản nào (organic) → dùng giá trị RC thường. REMOTE CONFIG Bản đang chạy chỉ có kịch bản ad_camp (campaign ROAS quảng cáo): banner bật, inter từ level 10, capping 60 s, 999/ngày. Bản mặc định trong code là iap_camp: tắt banner và Daily, inter từ level 30, capping 300 s, tối đa 7/ngày.

Luồng xử lý

  1. 1
    AppsFlyer trả campaignserver
    af_status=Organic hoặc tên campaign (ví dụ Colony_and_ADROASD28_ww_1206).
    SERVER/CDN
  2. 2
    Nạp JSON kịch bảnclient
    RC campaign_scenario_config, cache vào PlayerPrefs (campaign_scenario_cache_json); thiếu thì dùng BuiltInDefaultJson.
    CODEREMOTE CONFIG
  3. 3
    Khớp & ápclient
    Resolve() → Current; gửi event campaign_scenario_matched.
    CODE
  4. 4
    Mọi chỗ đọc ads/offerclient
    GetInterCapping(fallback) trả giá trị kịch bản nếu ≠ −1, không thì fallback × hệ số PostPurchase.
    CODE
