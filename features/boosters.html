Tổng quan

CONFIG 4 booster: Extra Slot (L3), Shuffle (L6), Pick Up (L9), Tornado (L16). Mỗi booster mở kèm popup “Booster Unlock” và tặng 2 lượt để học (PLAYTEST level 3). CODE BoosterManager.UseBooster rẽ nhánh UseBoosterAddSlot / UseBoosterShuffle / UseBoosterBalloon (Pick Up) / UseBoosterMagnet (Tornado — hút hết khối 1 màu, Level.ClearGunBulletCount). REMOTE CONFIG force_use_booster_config.IsForceUseBooster = 1: bật hướng dẫn ép dùng booster; giá mua lẻ trong màn lấy từ RC ingame_booster_config (NewPrice).
