Tổng quan

REMOTE CONFIG Khi thua cùng một level đủ LoseCountToShow = 12 lần, game mở popup “You've been trying really hard!”. CODE HelpWithAdsGoldManager chọn 1 loại popup/ngày: HelpWithAds (xem quảng cáo nhận +1 Slot / +1 Pick Up / +1 Tornado) hoặc HelpWithGold (mua bằng coin, ví dụ Slot 400, Tornado 400); loại dựa trên tổng booster/coin đang có so với ngưỡng AdsBoosterThreshold/AdsGoldThreshold/GoldBoosterThreshold/GoldGoldThreshold. Mỗi lựa chọn nhận 1 lần/ngày, có icon ở Home.
