Tổng quan

CONFIG Dữ liệu level chia hộp theo MapElevatorData (mỗi phần tử là một làn, giữ danh sách GunDatas theo thứ tự). Trung bình 4.4 làn, 45 hộp/level. Từ level 214 có GunSpawner (một ô sinh lần lượt nhiều hộp, 443 level) và từ level 567 có Hollow Log / TunelLock che N hộp cho tới khi ăn đủ số khối màu yêu cầu. CODE Slot mặc định = MaxGunStands; booster Extra Slot gọi GunBattleContainer.AddGunStandBooster; hồi sinh mở thêm ReviveSlot = 1.

Luồng xử lý

  1. 1
    Nạp lànclient
    Level.LoadGun dựng các làn từ MapElevatorData; LinkedGuns nối hộp giữa các làn.
    CODE
  2. 2
    Chọn hộpngười chơi
    Hộp nối (Linked) phải đi cùng nhau: cần đủ slot cho cả nhóm (CanLinkedGroupEscape).
    CODE
  3. 3
    Sắp xếp slotclient
    SortGunInStand, Reposition giữ slot gọn sau khi hộp biến mất.
    CODE
