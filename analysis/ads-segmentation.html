Phân khúc user theo campaign & quảng cáo

CampaignScenarioManager: organic vs ad_camp vs iap_camp.

💰 Kinh tế & kiếm tiền
Nhãn nguồn: CODE pseudo-C/khai báo class (Ghidra + Cpp2IL) · CONFIG ScriptableObject đóng gói · REMOTE CONFIG Firebase RC (template v306, fetch 22/10/2026) · SERVER/CDN backend/CDN/sheet · PLAYTEST LDPlayer v1.0.80 · DIỄN GIẢI nhận định của người viết.
Phân khúc user của Colony Flow không theo hành vi trong game mà theo nguồn UA: user đến từ campaign tối ưu quảng cáo bị dày quảng cáo hơn (inter từ level 10, cách 60 s), user đến từ campaign tối ưu IAP được bảo vệ (không banner, inter từ level 30, 300 s, ≤7/ngày) — ít nhất trong bản mặc định đóng ở code. Remote Config hiện chỉ giữ kịch bản ad_camp.

Luồng phân khúc

  1. 1
    AppsFlyer xác định nguồn càiserver
    af_status / tên campaign; nếu AppsFlyer chậm, CampaignNameFetcher hỏi wood.aagamestudio.com/api/appflyerdata/.
    CODE
  2. 2
    Chọn kịch bảnclient
    So khớp tên campaign với từng kịch bản (Exact / Prefix / Contains).
    CODE
  3. 3
    Ghi đè ads & shopclient
    Banner, inter (level/capping/ngày), inter khi thua, ads nạp tim, popup No Ads, Daily, gói ẩn/chỉ hiện.
    CODE
  4. 4
    Sau khi muaclient
    PostPurchase: ẩn banner trong phiên, nhân capping ×2, inter tối đa 3/phiên (đang tắt: Enabled=0).
    REMOTE CONFIG

Phân nhánh khác theo user

  • CODE Gói Shop ẩn/hiện theo kịch bản (HiddenPackages, VisiblePackagesOnly).
  • CODE Offer theo lịch sử mua: PackConditionGroup + PackBuyCount (đã mua gói X N lần).
  • REMOTE CONFIG Help with Ads vs Gold: chọn theo số booster/coin người chơi đang có (ngưỡng 1 / 500 / 4 / 900).
  • REMOTE CONFIG Firebase RC: 8 quốc gia thử đều nhận cùng template v306 — không có điều kiện theo nước.

Đánh giá

Điểm là đánh giá của người viết (1–5) dựa trên dữ liệu ở trên.

Tiêu chíĐiểmLý do
Đúng mục tiêu UA5/5Giữ trải nghiệm sạch cho user có giá trị IAP cao, khai thác quảng cáo user ad-ROAS.
Rủi ro3/5Organic rơi về fallback; nếu RC xoá kịch bản (như iap_camp hiện tại) thì nhóm đó mất bảo vệ.

Chưa biết

  • Nội dung RC các phiên bản template trước (chỉ đọc được v306).
  • Phân khúc nằm ở server (team, league group) — không thấy chia nhóm theo chi tiêu.
