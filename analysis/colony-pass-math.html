Toán Colony Pass

Tổng sao, số level cần, công thức Bonus Bank (chỉ sao vượt track).

🎪 LiveOps
Nhãn nguồn: CODE pseudo-C/khai báo class (Ghidra + Cpp2IL) · CONFIG ScriptableObject đóng gói · REMOTE CONFIG Firebase RC (template v306, fetch 22/10/2026) · SERVER/CDN backend/CDN/sheet · PLAYTEST LDPlayer v1.0.80 · DIỄN GIẢI nhận định của người viết.
Pass cần tổng 977 vé cho 31 tier; với 18 vé/10 level (7×1 + 2×3 + 1×5), hoàn thành pass ≈ 543 level trong mùa ~33 ngày (≈16 level/ngày). Bonus Bank chỉ tính vé vượt mốc 977: 5 coin/vé, trần 3.000 coin sau thêm 600 vé (≈876 level cả mùa). Playtest 28/10 xác nhận: 300 vé dư → 1.500 coin khi hết mùa.

Công thức (pseudo-C)

CODE get_UnlockedTierCount: duyệt tier, cộng dồn RequireStar, dừng khi tổng vượt số vé đang có. Bonus Bank = Math.Min(BonusBankCoinPerKey × max(0, Stars − StarsToCompleteTrack), BonusBankCapCoin), chỉ khi premium và đã mở tier cuối. Trong class BattlePassRemoteConfig chỉ còn BonusBankCoinPerKey (offset 0x3C) và BonusBankCapCoin (0x40); hai key RC BonusBankCoinPerStar/BonusBankMaxCoin là trường cũ, client không đọc.
