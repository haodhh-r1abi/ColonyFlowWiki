Hệ thống offer

Shop, popup cổng, chuỗi offer, gói thời hạn, gói khi thua.

💰 Kinh tế & kiếm tiền
Nhãn nguồn: CODE pseudo-C/khai báo class (Ghidra + Cpp2IL) · CONFIG ScriptableObject đóng gói · REMOTE CONFIG Firebase RC (template v306, fetch 22/10/2026) · SERVER/CDN backend/CDN/sheet · PLAYTEST LDPlayer v1.0.80 · DIỄN GIẢI nhận định của người viết.
Hệ offer gồm 5 lớp: Shop cố định (37 SKU), popup cổng (Starter Pack, No Ads 90% Off tối đa 2 lần/ngày), chuỗi offer (Jungle Treasure), gói thời hạn (Speedy Pack, Event offer theo dịp), và gói khi thua (Fail Offer $5.99). Điều kiện hiện gói nằm ở client (PackHandler) cộng bộ lọc theo campaign.

Điều kiện hiển thị

  • CODE PackHandler.CheckConditions duyệt mảng nhóm điều kiện; nhóm thoả → hiện gói (logic OR giữa nhóm, AND trong nhóm theo cấu trúc mảng).
  • CODE CampaignScenarioManager.IsPackageVisible lọc theo campaign.
  • REMOTE CONFIG is_after_inter được log khi mở popup bán hàng ngay sau interstitial.

Điểm là đánh giá của người viết (1–5) dựa trên dữ liệu ở trên.
