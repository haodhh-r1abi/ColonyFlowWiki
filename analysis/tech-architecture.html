Kiến trúc kỹ thuật & dữ liệu

Khởi động, CDN level, backend, mã hoá, phương pháp dịch ngược.

🔧 Kỹ thuật
Nhãn nguồn: CODE pseudo-C/khai báo class (Ghidra + Cpp2IL) · CONFIG ScriptableObject đóng gói · REMOTE CONFIG Firebase RC (template v306, fetch 22/10/2026) · SERVER/CDN backend/CDN/sheet · PLAYTEST LDPlayer v1.0.80 · DIỄN GIẢI nhận định của người viết.
Unity 6000.3.19f1 + URP, IL2CPP arm64, metadata v39 không mã hoá → dịch ngược được toàn bộ: Cpp2IL (160.520 method) → Ghidra (21.760 method game decompile được). Dữ liệu nhạy cảm chỉ được che bằng AES với key đóng cứng trong code.

Phương pháp đọc ngược

  • AssetRipper (HExportV2) → project Unity 8.092 stub, 305 prefab.
  • Il2CppDumper không đọc v39 → Cpp2IL diffable-cs → cs2dump.py (sửa lệch RVA +0x4000 giữa file offset và vaddr) → Ghidra apply/analyze/decompile.
  • Literal: tự giải metadata-usage qua relocation .got (58.839 tham chiếu gắn vào pseudo-C).
  • Key AES lấy từ literal của DataSerializer/LevelDataSerializer; hàm hoán vị đọc từ disassembly.

Điểm là đánh giá của người viết (1–5) dựa trên dữ liệu ở trên.
